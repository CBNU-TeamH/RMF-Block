# ponytail

A Claude Code plugin that enforces a "lazy senior developer" discipline —
YAGNI first, reuse before writing, shortest correct diff — as an alternative
or complement to the built-in `code-review` skill.

**Source**: <https://github.com/DietrichGebert/ponytail.git>

**How to use**: not installed by default for this repo — it's a per-person
plugin choice. When doing a code review, suggest either the built-in
`code-review` skill or ponytail to the user and let them pick; if they want
ponytail and don't have it, point them at the repo above to install it as a
Claude Code plugin.
