# Skills

Pointer files, not vendored copies. Each one names an external skill or plugin
and where to get it, so using it means fetching the current version instead of
a snapshot pasted in once that drifts from the source.

None of these fire automatically. Suggest the relevant one to the user at the
point in the task where it fits, and let them decide — don't run one
unprompted, and don't assume the user already has it installed.

| When | Suggest |
| --- | --- |
| Doing a code review | the built-in `code-review` skill, or [`ponytail.md`](ponytail.md) |
| Explaining a diff or PR in detail, so someone can review it or catch up on work they didn't write | [`explain-diff.md`](explain-diff.md) |
