# explain-diff

Walks through a diff or PR file by file — what changed and why — to close a
knowledge gap before merging something you didn't write, or before reviewing
your own past work months later.

**Source**: <https://gist.github.com/geoffreylitt/a29df1b5f9865506e8952488eac3d524>

**How to use**: fetch the gist and follow its instructions directly rather
than paraphrasing from memory, since the source can change. Suggest this to
the user when they ask for a diff or PR to be explained, or say they don't
follow a change — don't run it unprompted.
